Method and routes

Benchmark setup

  • Intel Core i7-13700, 24 logical CPUs; client and server shared the same machine.
  • PHP 8.6.0RC5 ZTS; both servers linked to the same PHP library. FrankenPHP 1.13.4 / Caddy 2.11.8; H2O 2.3.0-DEV.
  • 48 PHP workers per server. Symfony production environment, SQLite, and the default 500-request worker recycling on both.
  • One benchmark server at a time. Three independent starts per server; server order alternated between rounds.
  • Three-second warmup per route, then three 10-second measurements per point; median throughput reported.
  • wrk -c 1, 8, 32, 100, 256; up to eight client threads. Counts shown are the requested wrk -c values.
  • Plain HTTP/1.1 keep-alive over IPv4 loopback, with Host: localhost. The tests fetched HTML routes and did not fetch page assets.

Matching and validation

Production PHP INI/environment settings were matched in temporary benchmark configs. Deprecation logging and OPcache timestamp checks were disabled on both. The example configs and application files were left unchanged.

Each matrix contains 90 measured samples. Preflight checked HTTP 200 responses, matching page titles/headings, and worker mode. Tracing JIT was verified over HTTP before warmup, after warmup, and after measurement for all six JIT server starts. Neither benchmark server used swap.

JIT run: 5,873,529 requests, zero errors. Baseline: 5,547,480 requests, zero errors.
